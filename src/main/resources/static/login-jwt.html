Sistema de autenticación seguro usando JSON Web Tokens (JWT).

🛡️ Protección contra CSRF

✅ JWT NO es vulnerable a CSRF porque:
1. El token se almacena en localStorage (no en cookies)
2. JavaScript de otro dominio NO puede acceder al token
3. El token debe incluirse MANUALMENTE en cada request
4. Un atacante externo no tiene acceso al token
