Validación de Entrada con Bean Validation (JSR-380)

🔍 ¿Qué es SQL Injection?

SQL Injection es una técnica de ataque donde un atacante inyecta código SQL malicioso en campos de entrada para manipular la base de datos.

  • Objetivo: Obtener acceso no autorizado, robar datos, o destruir información
  • Método: Insertar caracteres especiales SQL en inputs (', --, OR, etc.)
  • Impacto: Puede comprometer toda la base de datos

✅ Protecciones Implementadas

  • @NotBlank: Campos no pueden estar vacíos
  • @Size: Longitud mínima y máxima definida (3-50 chars para username)
  • @Pattern: Solo caracteres alfanuméricos y guion bajo permitidos
  • JPA/Hibernate: Consultas parametrizadas automáticas (previene SQL injection)
  • GlobalExceptionHandler: Mensajes de error claros sin exponer información sensible

🔴 Ataque 1: SQL Injection Clásico

SQL INJECTION

Objetivo: Bypassear autenticación usando OR '1'='1

Username: admin' OR '1'='1
Password: cualquiercosa

SQL generado (vulnerable):

SELECT * FROM users WHERE username = 'admin' OR '1'='1' AND password = '...'

🔴 Ataque 2: Denial of Service

DOS ATTACK

Objetivo: Sobrecargar servidor con campos extremadamente largos

Username: "a".repeat(10000)
Password: "b".repeat(10000)

Impacto: Consume memoria, causa timeout, hace que la app no responda

🔴 Ataque 3: Cross-Site Scripting

XSS ATTACK

Objetivo: Inyectar JavaScript malicioso en campos de texto

Username: <script>alert('XSS')</script>
Password: password

Riesgo: Si se devuelve sin sanitizar, ejecuta código en el navegador

🔴 Ataque 4: SQL Injection con Comentarios

SQL INJECTION

Objetivo: Ignorar resto de query con --

Username: admin'--
Password: (ignorado por el comentario)

SQL generado (vulnerable):

SELECT * FROM users WHERE username = 'admin'-- AND password = '...'

🔴 Ataque 5: Validación de Longitud

VALIDATION BYPASS

Objetivo: Probar límites de longitud mínima/máxima

Username: ab (muy corto, min=3)
Password: 12345 (muy corto, min=6)

Esperado: Rechazo por no cumplir requisitos de longitud

🔴 Ataque 6: Caracteres No Permitidos

VALIDATION BYPASS

Objetivo: Usar caracteres especiales prohibidos

Username: admin@email.com
Password: password123

Regex: Solo permite [a-zA-Z0-9_], rechaza símbolos
