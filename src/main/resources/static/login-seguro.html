Esta página demuestra cómo realizar peticiones seguras con protección CSRF.

🛡️ ¿Cómo funciona la protección CSRF?

1. Obtenemos un token CSRF del servidor
2. Incluimos el token en el header X-XSRF-TOKEN
3. El servidor valida que el token sea correcto
4. Solo entonces permite la operación
